Issues hold the work: the task a `/bothub` comment starts from, plans, specs and every question a
bot could not answer alone. `issues.ts` defines the interface, `issues-github.ts` implements it over
the GitHub REST API and `issues-local.ts` over Markdown files in the hub. `hub.yaml` picks one.

## Local issues

Each issue is `issues/<n>-<slug>.md`. Comments are appended as `## @<author> at <time>` sections,
numbers are claimed with an exclusive lock file, and a watcher turns file changes into events, so a
comment typed into a file starts the same workflows a GitHub comment does.
