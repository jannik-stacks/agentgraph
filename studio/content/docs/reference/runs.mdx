## Running a session

<Sym name="runJob" /> starts the harness, streams its events into the store and never fails: a
timeout, a loop or a container that never started all become a run status. With
`BOTHUB_SANDBOX=docker` the session runs in a container built by <Sym name="dockerRun" />;
otherwise on the host with a private home. The setup is on [Sandbox and models](/docs/sandbox).
