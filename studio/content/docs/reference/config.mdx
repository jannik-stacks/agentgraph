Every hub file is Markdown with YAML frontmatter. `schema.ts` holds one zod schema per file kind,
and the TypeScript types are inferred from them, so the schema is the only definition. `load.ts`
reads a hub directory, `markdown.ts` splits each file into frontmatter and body, and `config.ts`
validates the lot into a <Sym name="Config" />.

## Compiling

<Sym name="readHub" /> collects the files, <Sym name="parseMarkdown" /> splits each one, and
<Sym name="compile" /> routes them by directory and checks every cross reference. It fails closed:
one error rejects the whole hub.
