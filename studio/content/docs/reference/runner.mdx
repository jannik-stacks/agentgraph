---
title: Runner and sandbox
description: How one agent session or script runs, on the host or in a container.
---

`runner.ts` starts a harness for one stored run, streams its output into the store, masks secrets
and records how it ended. `sandbox.ts` builds the `docker run` command when the run goes into a
container. `BOTHUB_SANDBOX=docker` picks the container; anything else runs on the host with a
private home. The setup itself is on [Sandbox and models](/docs/sandbox).
