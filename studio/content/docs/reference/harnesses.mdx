A harness is the agent CLI a bot runs in, picked by the bot's `harness`: **opencode** or **pi**.
Both talk only to the LiteLLM proxy, where a bot's `model` is an alias. The pipeline turns a job
into a session spec with <Sym name="buildSpec" />.

<Fields name="RunSpec" />

Every harness's output is normalised into the same events.

<Source file="src/types.ts" symbol="AgentEvent" />

## The adapter

An adapter builds the command for a spec and parses one output line at a time; the
[runner](/docs/reference/runs) does the spawning.

<Source file="src/types.ts" symbol="HarnessAdapter" />

opencode is the primary harness, with real tool allowlists and the bothub MCP server mounted. pi is
light and fast, with all-or-nothing tools and no MCP client, so it suits read-only bots.
`bothub sim` swaps both for a scripted adapter, see [Events and serving](/docs/reference/serve#sim).
