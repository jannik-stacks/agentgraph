---
title: Preload and tools
description: Context rendered into a run, and the read-only tools it can call.
---

A run gets context two ways. Preload is rendered into the prompt before the run starts. Tools are
served by the bothub MCP server, which the harness starts and the run calls when it needs to.
Both only read; writes go through [proposals](/docs/reference/proposals). The concepts are on
[Context](/docs/context).

## Preload

<Sym name="relevantNotes" /> picks the notes a run loads and <Sym name="renderNotes" /> renders them
into the system prompt. <Sym name="issueContext" /> renders the triggering issue and its links into
the prompt.
