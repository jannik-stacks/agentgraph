`cli.ts` is the `bothub` command. `serve.ts` is the long-running local hub that `bothub serve`
starts, `api.ts` the read-only HTTP API that BHM reads, and `graph.ts` the node and edge model the
Studio draws.

## A local hub

<Sym name="serveHub" /> watches the hub's `issues/` directory, runs the jobs each change starts
through the [pipeline](/docs/reference/pipeline) one event at a time, and serves the API. GitHub's
part is played by a local bare repository: <Sym name="localPulls" /> answers the few pull request
calls the pipeline makes and records opened pull requests in `pulls.jsonl`.

## The API

<Sym name="api" /> is a Web `Request` handler, so the same code can run behind `node:http` or a
Worker. It only reads: the hub's files, runs, their events (also as a live stream), outcomes, raw
harness files and the runs that need a human.
