Everything starts from a <Sym name="BotEvent" />. A GitHub delivery is checked by
<Sym name="webhook" /> and normalised by <Sym name="toEvent" />; a change to a local issue file is
turned into the same event by <Sym name="changeEvent" />.

<Fields name="BotEvent" />

## Serving

<Sym name="serveHub" /> is the local hub: it watches `issues/`, runs each change through the
[pipeline](/docs/reference/pipeline) one event at a time, plays GitHub's part with a local bare
repository and serves the read-only <Sym name="api" /> that BHM reads. <Sym name="serveGitHub" />
is the same for a GitHub App, with short-lived installation tokens that no bot ever holds.

## Sim

`bothub sim <scenario>` runs a hub against a scripted human action. Bots are replaced by a scripted
harness and checks by scripts that pass or fail as told; dispatch, the pipeline, the MCP server,
validation and apply are real. <Sym name="simulate" /> runs one.
