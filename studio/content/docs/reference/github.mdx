In GitHub mode, deliveries arrive at a webhook receiver, are checked and normalised into a
<Sym name="BotEvent" />, and run through the same [pipeline](/docs/reference/pipeline) as local
events. bothub acts on GitHub as a GitHub App with short-lived installation tokens; no bot ever
holds one.

## Serving

<Sym name="serveGitHub" /> puts it together: the receiver on its own port, the store's ledger
against repeated deliveries, the pipeline running as the installation that sent the event, and the
[API](/docs/reference/serve) on another port. Setting up the App is described in
[infra/github](/source/infra/github/README.md).
