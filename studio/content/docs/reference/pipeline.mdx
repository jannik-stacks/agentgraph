## The until loop

A bot job runs, then each check in its `until` runs against the worktree. Findings from failing
gating checks go back to the same bot as a follow-up prompt, until the checks pass, `until.max`
follow-ups are used or the bot's `usd-per-run` is spent. The loop is in
<Sym name="attempts" file="src/pipeline.ts" />. Every check ends in a verdict.

<Fields name="Verdict" />

A check gates when its mode is not `shadow`. Skipped only passes when the check allows it.

## Verdicts

A check is a script (exit code), a bot that replies `PASS` or `FAIL`, or a `decide` question to a
small local model (<Sym name="decideCheck" />). A bot that does not answer clearly fails.

<Source file="src/pipeline.ts" symbol="verdictOf" />

When a job's final run ends, <Sym name="summarize" /> writes a short memory of it next to its
events, without a model.
