A bot ends its reply with a fenced `bothub` block, read by <Sym name="extractProposals" />. The
concepts are on [Proposals](/docs/proposals).

<Source file="src/outputs.ts" symbol="Proposal" />

## Validation

<Sym name="validate" /> accepts only what the job explicitly allows and rejects the rest with a reason. Pushed files are
checked with <Sym name="checkPaths" />.

<Fields name="Validated" />

## Applying

<Sym name="apply" /> pushes first, then applies the rest in order. Each effect has a stable key and is journalled as
`pending` before anything happens, so a retry after a crash finds what an earlier run already did.
