## Decide

A check with `decide` asks a small local model one yes or no question about the changes, through
Ollama's decision API. It costs far less than a bot check and fails closed when the model cannot
be reached.

## Memory

When a job's final run ends, the pipeline writes a short summary of it next to its events: tools
used, files touched, what it proposed and what landed, which checks failed and what it cost. No
model is involved.
