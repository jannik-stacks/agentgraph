The studio Graph reads each way back's out-of-rounds mark from that outcome's own trace line, so a reason the run was given later, such as a rebase conflict, no longer marks the last way back as out of rounds. A check's Verdicts panel now shows a failed refresh over its earlier verdicts and offers a retry when the first load fails.

A missing tracker folder is now reported as a tracker folder with no origin.git.
