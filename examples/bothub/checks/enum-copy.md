No list the change adds copies every value of a string union the code declares, which would miss the next value the union gains, and no number it sets or compares under a name that src/ and a hub script both give that number.

A union's values live where it is declared. Derive the list from the declaration, or read it from
there in a hub script, so a new value reaches every place that lists them. A limit both the engine and
a hub script use lives in one of them, and the other reads it from there or gets it passed in.
