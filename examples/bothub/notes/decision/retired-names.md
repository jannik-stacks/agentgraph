The names below were replaced; the new one is used in code, comments, docs and hub files.

- executor became harness: the program that runs a bot's session (opencode, pi) is its harness,
  `harness:` in a bot file, `HarnessAdapter` in `src/types.ts` and `src/harnesses/` for the adapters
- soul became role
- persona became bot
- `can:` became `returns:`
- open-pr became merge-request
- for-each became `over:`
- extra prompt became prompt
- the convention and pattern note kinds became style

A line that quotes an old name, or names the new one beside it, is a hint about the name and stays
allowed.
